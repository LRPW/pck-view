## Возможности

### Операции с архивом

- Дерево каталогов с фильтром по пути и виртуализацией длинных списков.
- Размеры ресурсов, признаки сжатия и несохранённых изменений.
- Добавление, замена, удаление и экспорт отдельных файлов.
- Распаковка всего архива и упаковка папки в PCK с сохранением структуры путей.
- Прогресс длительных операций.

### Поиск по содержимому

Поиск выполняется в фоновом потоке. Параметры, прогресс и результаты отображаются в отдельном системном окне **Find in
Files**.

- Обычный текст, регулярные выражения, учёт регистра и целые слова.
- Автоматическое определение кодировки или явный выбор UTF-8, GBK, UTF-16 LE / BE.
- Совпадения появляются во время поиска, сгруппированы по файлам и показывают строку, столбец и фрагмент текста.
- Переход к найденному месту доступен сразу, до завершения поиска.
- Отмена сохраняет уже найденные результаты.
- Известные бинарные форматы пропускаются по умолчанию; их можно включить в поиск.
- Ошибка чтения одного ресурса не прерывает проверку остальных.

### Текстуры, изображения и медиа

| Ресурсы             | Предпросмотр                                                                        |
|---------------------|-------------------------------------------------------------------------------------|
| **DDS**             | DXT1 / DXT3 / DXT5, несжатые RGB / RGBA; поддерживаемые DXT-варианты заголовка DX10 |
| **TGA**             | Обычные и RLE, палитра, градации серого, прозрачность                               |
| **Изображения**     | PNG, JPEG, GIF, WebP, BMP, ICO, AVIF                                                |
| **Аудио**           | OGG / Opus, MP3, WAV, FLAC, M4A, AAC                                                |
| **Видео**           | MP4, WebM, OGV                                                                      |
| **Текст**           | Просмотр и редактирование UTF-8, GBK, UTF-16 LE / BE                                |
| **Бинарные данные** | HEX-представление первых 64 KiB                                                     |

Воспроизведение аудио и видео, а также часть форматов изображений зависят от доступных в WebView2 кодеков. Для DDS и TGA
используется отдельный декодер.

Управление изображением:

| Ввод                                            | Действие                                                    |
|-------------------------------------------------|-------------------------------------------------------------|
| Колесо мыши                                     | Масштабирование относительно положения курсора              |
| Перемещение с зажатой левой или средней кнопкой | Сдвиг изображения                                           |
| Двойной щелчок / **Вписать**                    | Вписывание в область просмотра                              |
| **100%**                                        | Один пиксель текстуры на один CSS-пиксель области просмотра |

Прозрачные области отображаются на клетчатом фоне.

### Локализация

**RU / EN** переключает язык интерфейса без перезапуска. Выбор сохраняется и применяется к основному окну и окну поиска.
Системные элементы диалогов выбора файлов могут следовать языку Windows.

## Использование

1. Откройте `.pck` кнопкой **Открыть PCK** или сочетанием `Ctrl+O`.
2. Выберите ресурс в дереве. Для поддерживаемых изображений и медиа автоматически откроется предпросмотр.
3. Используйте **Текст**, **HEX** или **Предпросмотр**, чтобы выбрать нужное представление.
4. Для поиска по содержимому нажмите `Ctrl+Shift+F`.
5. Сохраните изменения через `Ctrl+S` или создайте отдельную копию через `Ctrl+Shift+S`.

Изменения ресурсов хранятся в памяти до сохранения архива. **Применить текст** обновляет ресурс в памяти; сохранение
архива также применяет текущую незавершённую текстовую правку.

### Распаковка

Нажмите **Распаковать всё** и выберите папку назначения. Пути ресурсов сохраняются относительно её корня. Существующие
файлы по тем же путям заменяются, остальные файлы папки остаются на месте. При ошибке ранее извлечённые ресурсы
сохраняются.

### Упаковка

Нажмите **Запаковать в PCK**, выберите папку ресурсов и путь нового архива **вне этой папки**. После упаковки архив
откроется в приложении. Пустые каталоги не сохраняются; ссылки и junction отклоняются.

## Сборка

Команды выполняются из каталога проекта, содержащего `package.json`.

### Требования

- Windows с установленным **WebView2 Runtime**.
- **Node.js** с npm.
- **Rust** с MSVC toolchain.
- **Visual Studio Build Tools** с инструментами MSVC и Windows SDK.

### Режим разработки

```powershell
npm install
npm run tauri dev
```

### Готовое приложение

```powershell
npm run tauri build
```

Исполняемый файл: `src-tauri/target/release/pckview.exe`.

Создание установщика отключено в конфигурации. Иконки приложения находятся в `src-tauri/icons/lrpw/`.

### Проверки

```powershell
# Локализация и декодеры текстур
npm test

# TypeScript и production-сборка интерфейса
npm run build

# Тесты бэкенда
cargo test --manifest-path src-tauri/Cargo.toml
```

Некоторые тесты бэкенда создают и заменяют временные файлы; для них нужен доступ на запись. Проверка локальной игровой
установки отключена по умолчанию.

## GitHub Actions и Releases

Workflow: [`.github/workflows/pckview.yml`](.github/workflows/pckview.yml). Каталог с этим README должен быть корнем
GitHub-репозитория.

- Push в ветку, pull request или ручной запуск выполняют проверки и сборку Windows x64.
- Зависимости интерфейса устанавливаются по `yarn.lock`, Rust — по `Cargo.lock`. Перед сборкой выполняются `npm test` и
  тесты Rust.
- EXE и `SHA256SUMS.txt` доступны в артефакте `pckview-windows-x64` в течение 14 дней.
- Push тега `pckview-v*` или `v*` после успешной сборки публикует EXE и контрольную сумму в GitHub Releases. Версии с
  суффиксом, например `0.2.0-beta.1`, публикуются как prerelease.
- Дополнительный токен не требуется: workflow использует встроенный `GITHUB_TOKEN`. Права публикации выделены отдельному
  заданию.

Для выпуска версии синхронизируйте `version` в `package.json`, `src-tauri/tauri.conf.json` и `src-tauri/Cargo.toml`.
После изменения версии Rust обновите `Cargo.lock`, например командой `cargo check --manifest-path src-tauri/Cargo.toml`,
и включите изменения в коммит. Версия тега должна совпадать с версией приложения.

Пример публикации текущей версии:

```powershell
git tag pckview-v0.1.0
git push origin pckview-v0.1.0
```

Имя файла в релизе: `LRPW-PCK-View-0.1.0-windows-x64.exe`. Это исполняемый файл без установщика; для запуска нужен
WebView2 Runtime.

## Формат и ограничения

| Параметр             | Поддержка                                                  |
|----------------------|------------------------------------------------------------|
| Версия PCK           | `0x20002`                                                  |
| Профили              | Стандартный, `171`, custom/update (`0`), `111`             |
| Таблица ресурсов     | Записи 276 и 288 байт, zlib, safe header                   |
| Имена файлов         | GBK, до 259 байт                                           |
| Разделённые архивы   | Чтение PCK с соседним PKX; граница `0x7fffff00`            |
| Сохранение           | Одиночный PCK меньше `0x7fffff00` байт — чуть меньше 2 GiB |
| Зашифрованные архивы | Чтение и экспорт; изменение отключено                      |
| Отдельный ресурс     | До 256 MiB для предпросмотра, поиска, импорта и экспорта   |
| Полная распаковка    | Без лимита предпросмотра 256 MiB на ресурс                 |
| Результаты поиска    | До 5000 совпадений с явной отметкой о достижении лимита    |

Сохранение выполняется во временный файл в каталоге назначения. Перед заменой целевого файла проверяется записанный
архив. Неизменённые сжатые ресурсы копируются без повторной упаковки.

Поддержка DDS не охватывает все существующие форматы DXGI: например, BC6H и BC7 не декодируются. Предпросмотр показывает
основной уровень текстуры, без переключения mip-уровней и граней cubemap.

Отмена поиска проверяется между файлами и после чтения текущего ресурса. На большом сжатом файле остановка может
произойти с задержкой.

## Структура проекта

```text
src/
├── app/                 Состояние основного окна и действия с архивом
├── features/
│   ├── archive/         Дерево ресурсов и индексация
│   ├── search/          Отдельное окно поиска
│   └── media/           Предпросмотр, плеер и управление изображением
├── lib/textures/        Декодеры DDS и TGA
├── i18n/                Переводы RU / EN
├── styles/              Стили интерфейса
└── main.tsx             Точка входа React

src-tauri/
├── src/
│   ├── app.rs           Операции с архивом и команды приложения
│   ├── search/          Фоновый поиск и отмена
│   ├── tests/           Тесты формата и файловых операций
│   └── main.rs          Точка входа Rust
├── capabilities/        Разрешения окон
├── icons/lrpw/          Иконки приложения
└── tauri.conf.json      Конфигурация

tests/                   Тесты локализации и декодеров
assets/icon-concepts/     Исходные варианты иконок
```

Каталоги `node_modules/`, `dist/`, `src-tauri/target/` и `.logs/` содержат локальные зависимости, результаты сборки и
журналы.
