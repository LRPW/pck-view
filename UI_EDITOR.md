# Редактор AUInterface

Цель: редактор интерфейсов ElementClient с сохранением ресурсов и точным отображением на основе исходников
AUInterface/GfxCommon.

## Реализовано

- Дерево XML, включая Text, Resource и вложенные параметры.
- Изменение существующих и добавление XML-атрибутов.
- История Undo/Redo в пределах открытого редактора.
- Передача изменений в текстовый редактор: «Применить текст», затем сохранение PCK.
- Предпросмотр геометрии, текста, рамок и состояний кнопок.
- Чтение текстур из текущего PCK и соседнего surfaces.pck.

## Обязательные следующие этапы

1. Холст: единое выделение с деревом, перемещение, изменение размеров, сетка, привязки, направляющие, выравнивание,
   порядок слоёв, блокировка и скрытие.
2. Документ: создание/удаление/дублирование контролов, буфер обмена, сохранение неизвестных полей, проверка имён и
   ссылок, тесты XML round-trip.
3. Контролы: точное воспроизведение каждого типа из AUIDialog::InitFromXML; текст, списки, поля ввода, прокрутка,
   индикаторы, вложенные окна.
4. Ресурсы: браузер текстур, выбор состояний, атласы и спрайты, диагностика ссылок, управление связанными PCK,
   инвалидация кеша.
5. Текст: игровые шрифты, измерение, переносы, цветовые коды, градиенты, тени, контуры и локализация.
6. GFX: парсер формата по GfxCommon, таймлайн, частицы, зависимости, предпросмотр анимации и её редактирование.
7. Lua/команды: навигация по привязкам, редактор скриптов, диагностика; выполнение только в отдельной ограниченной
   среде. C++-обработчики требуют самого клиента.
8. Проект: DCF и темы, наборы окон, разрешения и масштаб, сравнение с клиентом, экспорт и резервные копии.

## Ограничения текущей версии

Предпросмотр не является запуском AUInterface. Полная совместимость не подтверждена. Холст пока не поддерживает
перетаскивание. Панель свойств редактирует атрибуты; структура XML сохраняется через DOM-сериализацию, форматирование
файла может измениться. История сбрасывается при закрытии редактора. Нужна визуальная проверка на реальном наборе
игровых ресурсов.
